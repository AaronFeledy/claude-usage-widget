Update Headroom

Headroom currently runs from a local source build. The project's existing release automation publishes Windows executables; those cannot update the Linux client. The app's release checker reports whether a compatible Linux package has been published.

Rebuild your local checkout

Use the checkout that contains clients/linux. First save or commit any local changes. Review incoming changes before updating your checkout; the app does not fetch or run downloaded code. If a desired revision does not contain clients/linux, it cannot build Headroom.

These commands build the source already in your checkout. They do not fetch an update from the network. Run them from the repository root:

cmake -S clients/linux -B clients/linux/build -DCMAKE_BUILD_TYPE=Release
cmake --build clients/linux/build --parallel
ctest --test-dir clients/linux/build --output-on-failure

After the build and tests succeed, choose Quit Headroom in the tray menu, then install and reopen:

cmake --install clients/linux/build --prefix "$HOME/.local"
"$HOME/.local/bin/headroom"

The install updates the executable and shared app files. Your connection settings, saved provider order, and bearer token stay in their existing configuration file. A custom installation prefix should use the same prefix for subsequent installs.

Requirements

CMake 3.21+, a C++17 compiler, and Qt 6.6+ with Quick, Quick Controls 2, Widgets, Network, SVG image support, and Test. Tests use a loopback HTTP server and a software-rendered Qt window.
